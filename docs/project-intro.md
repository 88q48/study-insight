## 三、完整简介（200 字左右）

学生手上有两个东西：一叠错题，一份屏幕使用时间。前者记录错了什么，后者记录花了多少时间，
但两者从来是分开的。结果是错题本越记越厚，时间也没少花，却说不清问题到底出在哪。

学情洞察把这两条线拼在一起。错题这边看三项：哪一科错得最多、哪个知识点反复出错、
每天的错题是被消化掉了还是越积越多，用雷达图、薄弱榜和消化漏斗呈现。专注这边看时长和产出，
把每天的学习时长和当天消灭的错题数画在同一张双轴图上，柱子很高而折线很平的日子，
就是投入和产出脱节的日子，系统会直接点出来。

技术上，Windows 客户端用 ctypes 调 Win32 API 采集前台窗口和空闲状态，
FastAPI 负责数据接入与统计，看板用 Streamlit 和 ECharts 两套方式实现，
手机上通过 React Native 录入错题。

## 五、推介时的说法（口头讲）

有人问「和普通错题本有什么区别」，可以这么答：

普通错题本只告诉你错了什么。这个系统还会告诉你：这一科的错误是不是集中在某一类题上，
你的时间是不是花在了不产生效果的地方。

有人问「和屏幕时间监控有什么区别」：

屏幕时间只统计用了多久，不在乎你学了什么。我们把时长和当天的错题消化量放在一起看，
时长本身不是目标。
